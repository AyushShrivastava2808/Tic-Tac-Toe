# 🎮 Tic Tac Toe Game

A fun and interactive **Tic Tac Toe** game built with **HTML, CSS, and JavaScript**.  
This project is simple, responsive, and beginner‑friendly — perfect for learning web development basics or enjoying a quick game of Xs and Os.

---

## ✨ Features
- Two‑player gameplay (X vs O)
- Automatic **win detection** with all possible winning patterns
- **Draw detection** when the board is full and no winner is found
- **Reset button** to start a new game instantly
- Responsive design using `vmin` units for smooth scaling
- Clean and modern UI with bold, centered X and O

---

## 🛠️ Technologies Used
- **HTML5** → Game structure  
- **CSS3** → Styling and layout  
- **JavaScript (ES6)** → Game logic and interactivity
